# A first tour of Lean

## Setup

1. Install Lean from <https://lean-lang.org/install> (this installs `elan` and the VS Code extension).
2. Clone this repository and run `lake build` from its root.
3. Open the folder in VS Code.

## Where to go next

- [Mathematics in Lean](https://leanprover-community.github.io/mathematics_in_lean/): the standard tutorial for mathematics with Mathlib.
- [Mathlib documentation](https://leanprover-community.github.io/mathlib4_docs/): search for lemmas by name or statement.
- [Natural Number Game](https://adam.math.hhu.de/#/g/leanprover-community/nng4): the natural numbers from scratch, as an interactive game.
